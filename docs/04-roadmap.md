# Roadmap

## MVP

- Flutter app skeleton.
- Mock auto-counter.
- Local sessions.
- Offline sync queue.
- Supabase auth.
- Supabase session sync.
- Personal stats.
- Verified leaderboard.
- Premium family/friends groups.

## V1

- Native audio capture.
- TFLite/LiteRT model placeholder.
- Confidence scoring.
- Boundary detection.
- Correction UX.
- Group leaderboard.
- Subscription gating.

## V2

- User voice calibration.
- Personalized chanting speed profile.
- Playback risk scoring.
- Better benchmark dataset.
- Android and iOS real-device test matrix.

## V3

- Verified chanting dataset.
- Model versioning and rollout.
- Family challenges.
- Temple group pilot.
- Seasonal chanting challenges.

## Long-Term Moat

- Personalized chanting model.
- Family/community graph.
- Temple ecosystem.
- Festival and regional intelligence.
- Spiritual journey dashboard.
- Reputation score based on consistency and verification quality.

## Things Not To Build Too Early

- AI spiritual companion.
- Global heat map.
- Donations.
- Huge mantra catalog.
- Complex admin dashboard.
- Full temple platform.

Build only after the core counter and groups show real retention.
